# IDO Arquitectura

Landing de IDO Arquitectura ("Ideas con denominación de origen"), estudio de arquitectura e interiorismo en Caracas.

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:7273/
npm run build
```

Stack: Vite + React + TypeScript + Tailwind. Ver `CLAUDE.md` para la organización del código y las reglas.

## Documentos

- `docs/guion-landing.md`: guion de contenido extraído del Canva, identidad visual y pendientes.
- `docs/estructura-visual.md`: dirección visual, wireframes por sección e interacciones.
- `docs/assets/`: recortes de referencia del equipo y logo.
